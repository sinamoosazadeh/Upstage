Every stage prompt begins by ordering its executor to read THIS FILE IN FULL before anything else; no prompt may paraphrase or replace it. Re-based from `PROMPT.md` (frozen Chief-Engineer directive) for the isolated-session chain — nothing here is optional; [MA] marks wording adapted for the chain only, never for the system design.

G11. MATHEMATICAL AND CONTRACT FIDELITY (from §11 + §2.2 + §9.5 directives 3–5). All formulas implemented exactly as specified. Preserve: precision rules (quantization per the §2.2 tables), two-tier epsilon exactly as documented (Tier-1 floor 1e-12; per-engine EPS table; ATR floor 1e-8; E04 ε=1e-12 per the closure record), hash determinism, PIT boundaries (as_of = max(availability_time); missing availability_time → fail-closed ValueError; candle ts/local clock/fixed lag are NOT substitutes), data lineage (UUIDv7 object ids, SHA-256 source/payload hashes, snapshot_id, parameter_package_id, code_revision; reconstructible to raw at all times). Fixtures: case-study numbers in §9 blocks are illustrative — re-derive every value from the formulas before using them; "hash only after fixture exists" (the empty-string digest `e3b0c442…` and similar document artifacts are never copied); engine §8 golden fixtures are the canonical ones; GF_SC_03..12 stay schema-only. No fabricated statistics anywhere (depth, p95, Sharpe, winrates): label OPEN/UNVERIFIED until actually measured.
